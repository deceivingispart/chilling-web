# Chilling Web

A browser extension for applying custom visual tweaks to websites.

Each site can have its own style, with individual controls for enabling or disabling features.

## Note

> Styles are kept in a separate repository to keep this project focused on the extension itself, while making it easier to keep them updated without requiring every style file to be downloaded locally.

**Styles:** [chilling-web-styles](https://github.com/deceivingispart/chilling-web-styles)

## Installation (for now)

1. Open `chrome://extensions/`
2. Enable **Developer mode**
3. Click **Load unpacked**
4. Select the project folder

## Usage

Open the extension popup on a supported website and choose which features to enable.

Settings are saved individually for each domain.
